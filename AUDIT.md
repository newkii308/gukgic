# GUKGIC User App — Baseline Audit Report (Phase 0)

| Feature / Domain | Current Status | Mock vs Real | Identified Issues & Gaps | Required Fix / Real Implementation | Priority |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Authentication** | Partially Real | Mock Fallback | Uses `user_me` fallback and Header demo dropdown; missing dedicated login/register pages and server middleware protection. | Create real `/login` and `/register` pages with form validation; remove `user_me` fallback; enforce JWT cookies with server-side middleware. | **P0** |
| **Database & Persistence** | In-Memory / JSON | File Mock | `src/lib/db.ts` uses in-memory arrays; lacks real relational integrity, foreign keys, and indexes. | Implement Prisma ORM with SQLite (local) / PostgreSQL (production) with full relational models, migrations, and unique constraints. | **P0** |
| **User Profile** | Functional | Semi-Mock | Edits work in memory/file, but relies on initial mock users array. | Real Prisma User model; update profile updates DB directly; profile view fetches from DB. | **P1** |
| **Friend System** | Functional | Semi-Mock | Add/Accept/Reject works on memory arrays; lacks database relational constraints. | Implement `Friendship` & `FriendRequest` tables with duplicate prevention, block checks, and transactional integrity. | **P1** |
| **Social Feed** | Functional | Semi-Mock | Initial posts hardcoded; like toggle is global rather than per-user relational like table. | Implement `Post`, `PostLike`, and `PostComment` Prisma models with user-specific like checks and cursor pagination. | **P1** |
| **Real-time Chat** | Functional | Semi-Mock | Socket server works, but messages store in memory array; conversation authorization needs strict validation. | Store messages in database before socket emission; authenticate socket handshake via JWT cookie; enforce conversation member access. | **P1** |
| **Voice Messaging** | Functional UI | Sample Audio Mock | UI records audio and calculates waveform, but sends mock URL instead of saving uploaded audio file. | Create `/api/upload` endpoint to stream and save real `.webm`/`.wav` voice recordings; link real audio URLs to messages. | **P1** |
| **Notifications** | Functional | Semi-Mock | Stored in memory; needs database persistence with read/unread flags linked to user IDs. | Create `Notification` model with indexed `userId` and `isRead` queries; live trigger on friend/like/comment/message events. | **P1** |
| **Search & Discovery** | Functional | Semi-Mock | Filters in-memory users; needs real database query with debounce and interest/city filters. | Implement Prisma search queries with case-insensitive matching across username, name, city, and bio. | **P1** |
| **Settings & Privacy** | Functional UI | Semi-Mock | Settings UI exists, but privacy controls need database enforcement during feed and friend queries. | Store user preferences in `User` model; enforce privacy visibility (public/friends/private) server-side on queries. | **P1** |
| **Error Handling & UX** | Good UI | Needs Real States | Needs explicit empty states ("ຍັງບໍ່ມີໝູ່ເທື່ອ", "ຍັງບໍ່ມີຂໍ້ຄວາມ"), loading skeletons, and friendly Lao error toasts. | Standardize Lao error messages, loading skeletons, and empty state cards across all tabs. | **P2** |
